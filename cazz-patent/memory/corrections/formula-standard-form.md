# 数值积分演化格式标准形式规范

- **规则ID**: rule-008
- **严重级别**: important
- **领域**: 通用
- **来源**: 提案9（基于双曲平均曲率流与器官分界面拓扑约束的多器官联合分割方法）v1→v2 迭代
- **添加日期**: 2026-08-11
- **置信度**: 0.50

## 背景

提案9 v1 的 Stage 5 审核发现，方法类(2.2节)中的核心数值格式——速度-维莱特（Velocity-Verlet, VV）积分更新式存在**隐式自引用**：速度更新式 `v^{n+1} = ... - βv^{n+1}` 中，待求量 `v^{n+1}` 同时出现在自身的左右两端。该写法非公认标准形式，构成推导逻辑上的不一致，审查员会判定为公式错误。修复后改写为标准三步式（半步速度 → 位置 → 整步速度）。

## 规则内容

方法类中的数值积分/演化格式（速度-维莱特、欧拉法、Runge-Kutta 等）应使用**公认标准形式**，避免在同一更新式中出现隐式自引用。速度-维莱特标准三步式：

```
v^{n+1/2} = v^n + (Δt/2) · a^n                （半步速度）
φ^{n+1}   = φ^n + Δt · v^{n+1/2}              （位置推进）
v^{n+1}   = v^{n+1/2} + (Δt/2) · a^{n+1}      （整步速度，a 为加速度/变分导数）
```

其中加速度含阻尼时，阻尼项按半步速度显式化处理。

## 检查方法

1. 检查每个更新式中是否出现"某变量 n+1 步同时出现在自身更新式左右两端"的自引用
2. 检查是否使用公认标准形式（三步式/半步量显式化）
3. 隐式自引用出现即标记为"严重问题"，建议改写为标准三步式

## 违规后果

非标准/自引用的数值格式在专利审查中会被质疑推导严谨性，影响交底书的可置信度与可实现性（enablement）。
