# 术语中英文首次定义规范

- **规则ID**: rule-004
- **严重级别**: critical
- **领域**: 通用
- **来源**: 提案3 v1→v2 迭代
- **添加日期**: 2026-06-06
- **确认次数**: 2 | **有效性**: 0.80

## 背景

提案3 v1 中多处专业术语直接使用缩写而未给出全称（如直接写"FEM"而未先写"有限元方法(Finite Element Method, FEM)"），导致非该子领域的审阅者阅读困难。此为非技术性但严重影响可读性的问题。

## 规则内容

全文所有专业术语在首次出现时必须给出完整的中英文全称和缩写：

**格式**: `中文全称(English Full Name, ABBR)`

**覆盖范围**:
- 算法名称: Marching Cubes(移动立方体, MC)
- 评估指标: Dice Similarity Coefficient(Dice相似系数, DSC)
- 技术框架: Finite Element Method(有限元方法, FEM)
- 数据结构: Signed Distance Field(有符号距离场, SDF)

**注意事项**:
- 不得假设读者知道任何缩写
- 同一术语的第二次及后续出现统一使用缩写
- 缩写应选择领域通用缩写，而非自创缩写
