# 专利规避性辞藻规范

- **规则ID**: rule-006
- **严重级别**: important
- **领域**: 通用
- **来源**: 提案6-1/6-2/7-1/7-2 v1-review-pass
- **添加日期**: 2026-07-29

## 背景

在提案6-1/6-2/7-1/7-2 v1 的 Stage 5 审核中，四份交底书均被发现在2.1、2.3和技术效果中使用了过于绝对和夸张的表述辞藻——"首次将"、"根本性"、"完全消除"、"突破"等。专利交底书应使用客观、保守的陈述方式，不需要证明首创性或宣传性渲染。

## 规则内容

撰写交底书全文时，应避免以下类别的表述，改用更保守的等价表述：

| 避免使用 | 替换为 |
|---------|--------|
| "首次将...引入" | "将...引入" |
| "根本性改变/缺陷/提升" | "改变/问题/提升"（直接删除"根本性"） |
| "从根本上避免了" | "避免了" |
| "完全消除了" | "避免了"或"降低了" |
| "突破了...限制" | "不受...限制" |
| "开创性"、"独创"、"率先" | 直接删除 |
| "颠覆了"、"彻底解决" | 直接删除 |
| "重大突破"、"完美" | 直接删除 |

## 检查范围

全文所有章节（1.1-四），重点检查 2.1 创新点总结和 2.3 技术效果。

## 检查方法

使用关键词搜索：`首次|创新性地|根本性|根本缺陷|从根本上|突破|首次将|开创|前所未有|颠覆|彻底解决|完全消除|完美|重大突破|开创性|独创|率先`

## 违规后果

过度宣传性表述可能导致专利审查员质疑客观性，在专利实审中被要求删除或修正。

## 最近确认（提案9, 2026-08-11）

提案9 v1→v2 审核发现 2.1 使用"突破了水平集方法单器官独立演化的局限"，已改为"相较现有水平集方法单器官独立演化的实现"。再次确认"突破"类辞藻触发修正，eff 0.60→0.70，confirm_count 4→5。
