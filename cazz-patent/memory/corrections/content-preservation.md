# 原始提案内容保留原则

- **规则ID**: rule-001
- **严重级别**: critical
- **来源**: 提案3（器官数字模型构建方法）v1→v2 迭代
- **添加日期**: 2026-06-04
- **置信度**: 0.75

## 背景

在提案3 v1 撰写中，Agent 对原始提案中已有内容的三个章节进行了大规模重写，导致关键术语和原始技术表述丢失，提案人无法识别自己的方案。此问题直接触发了 v1→v2 迭代。

## 规则内容

撰写交底书时，以下章节的**已有内容必须逐字保留原文，不得重写**：

| 章节 | 处理方式 |
|------|----------|
| 1.1 技术背景 | 如已有内容则逐字保留；仅在明显残缺（如标注"请补充"）时补充 |
| 1.2 现有技术方案的缺陷 (即原始文档1.3) | 保留原文；可补充新条目但不得删除已有条目 |
| 2.1 创新点总结 | 保留原文作为第一段；可扩展其后内容 |

## 操作要求

1. 撰写前必须先读取 `需求输出/md/` 中对应的原始 .md 文件
2. 逐节比对原始内容与撰写内容，确保受保护的章节完全一致
3. 仅补充空白或明确标注"请补充"的部分
4. 核心任务是为 2.2（方法类）、2.3（技术效果）、三（附图及标记）、四（具体实施方式）补全内容

## 违规后果

重写原始内容会导致：提案人无法识别自己的方案、关键术语丢失、原始技术表述被弱化、模板审阅不通过。
