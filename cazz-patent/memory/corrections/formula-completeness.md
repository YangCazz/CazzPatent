# 数学公式符号完整性逐式检查

- **规则ID**: rule-002
- **严重级别**: critical
- **来源**: 提案3（器官数字模型构建方法）v2→v3 迭代
- **添加日期**: 2026-06-04
- **置信度**: 0.75

## 背景

提案3 v2 审核发现，方法类(2.2节)中 20 条数学公式存在符号未定义或解释缺失的问题。每一个未定义的符号都代表一个读者无法理解的知识断点，严重影响交底书的可读性和专利审查通过率。此问题触发了 v2→v3 迭代。

## 规则内容

方法类中 **每个数学公式（$$...$$ 块）的每个符号必须逐个定义**，公式后的符号解释段落必须覆盖公式中出现的 **每一个** 变量、算子、集合、标志符。

## 已知易遗漏符号清单

| 分类 | 符号示例 | 说明 |
|------|----------|------|
| 分布符号 | `U(·)`, `N(μ,σ)`, `Bern(p)`, `Cat(π)` | 概率分布需给出分布的完整名称和参数含义 |
| 积分域 | `dΩ`, `Ω_e`, `∫_Ω` | 积分域必须在第一次出现时就明确其空间含义 |
| 导数标记 | `u_dot`, `u_ddot`, `∂/∂t` | 时间导数、空间导数的标记方式需要提前约定 |
| 指示函数 | `1[condition]`, `I(·)` | 需要定义示性/指示函数的返回值和触发条件 |
| 损失函数 | `L_constraint`, `L_data`, `L_reg` | 每个损失项的金字塔来源和物理含义 |
| 索引变量 | `N_v`, `K_e`, `i`, `j` | 索引的范围和遍历含义 |

## 检查方法

1. 提取公式中出现的所有独立符号（变量、运算符、函数、集合标识符）
2. 在公式后面的段落中逐一搜索每个符号的定义
3. 任何未定义的符号标记为"严重问题"
4. 使用公式编号（如公式(3)）进行逐式核对，确保无遗漏

## 注意

标准算符（=、+、-、×、÷、∫、∑、∏、∂）无需每次定义；但特殊记号如 `⊙`、`⊗`、`∘` 等需要在首次出现时说明其在此上下文的含义。
