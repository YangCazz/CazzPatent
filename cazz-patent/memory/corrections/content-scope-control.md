# 新增内容有效甄别与篇幅控制规范

- **规则ID**: rule-009
- **严重级别**: important
- **领域**: 通用
- **来源**: 提案9（基于双曲平均曲率流与器官分界面拓扑约束的多器官联合分割方法）v2→v3 迭代
- **添加日期**: 2026-08-11
- **置信度**: 0.50

## 背景

提案9 v2 的背景部分相对底稿（需求文档）扩充过度：底稿背景约 700 字，v2 背景膨胀至约 2800 字（约 4 倍）。用户反馈"背景部分相对于底稿增加的太多了"。v2→v3 通过有效内容甄别压缩至约 2100 字（缩减 24.6%），保留支撑创造性的有效骨架，删除与实施例重复的器官毗邻逐项枚举、泛泛的技术铺陈与冗余细节。

## 规则内容

撰写交底书背景及正文时，相对底稿新增的内容应做**有效内容甄别**：

| 新增内容类型 | 判定 |
|-------------|------|
| 技术问题陈述 | 保留（压缩措辞） |
| 现有技术对比（最接近方案） | 保留（每条压缩，保留方法名+关键机制+与本发明差异点） |
| 缺陷-方案映射 | 保留（压缩描述） |
| 关键反驳论证（如"为何像素分类不够"） | 保留（与问题陈述合并压缩） |
| 与实施例重复的铺陈（器官毗邻枚举等） | 删除 |
| 泛泛的技术介绍/铺陈句 | 删除或大幅压缩 |

底稿原文内容仍须逐字保留（见 [[content-preservation]] rule-001）。

## 检查方法

1. 对比底稿(需求文档)原文，核对 rule-001 原文是否逐字保留
2. 甄别新增内容类型，删除冗余铺陈
3. 背景篇幅相对底稿明显膨胀（数倍）即标记为"一般问题"

## 违规后果

背景过度扩充会稀释发明点的聚焦度，增加审查员阅读负担，且冗余描述可能引入新的不一致或不确定性。
